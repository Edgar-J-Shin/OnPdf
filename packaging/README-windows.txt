OnPdf — PDF 뷰어·편집기 (Windows x64, 무설치)

설치 파일
  시작 메뉴·"연결 프로그램" 등록·제거가 필요하면 같은 릴리스의 OnPdf-<버전>-windows-x64-setup.exe 를 쓰세요.
  이 zip 은 같은 내용물의 무설치판입니다.

실행
  이 폴더의 onpdf_app.exe 를 실행합니다. 설치 과정은 없습니다. 폴더째 원하는 곳에 두고 쓰세요.
  PDF 파일을 onpdf_app.exe 위로 끌어 놓아도 열립니다.

첫 실행 경고
  아직 코드 서명 인증서가 없어 Windows SmartScreen 이 "Windows의 PC 보호" 창을 띄울 수 있습니다.
  "추가 정보" → "실행" 을 누르면 열립니다. 내려받은 파일이 맞는지는 릴리스의 SHA256SUMS.txt 로 확인할 수 있습니다.

요구 사항
  Windows 10 이상, x64.
